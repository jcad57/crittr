# Crittr subscription flow — design concept v1

Generated with the built-in imagegen tool on October 28, 2026. These are visual iteration artifacts; the tier implementation does not ship this proposed redesign.

## Boards

1. [Paywall and checkout](01-paywall-checkout.png): contextual limit sheet, main plan selection, purchase review, native store confirmation.
2. [Activation and setup](02-activation-setup-v2.png): activation, welcome, optional co-care invite, first Pro action.
3. [Management and recovery](03-management-recovery.png): returning to Free, managing a subscription, pending payment, restoring/retrying access.

## Design direction

Follow the current code's cream (#FAF7F1), orange (#FD8A2D), espresso (#2A2624), and pastel palette. Use Fredoka headings, Nunito body text, rounded cards and the existing orange button's lower shadow. Pet illustrations introduce warmth; keep forms and plan comparison easy to scan.

The 12 screen concepts cover the primary purchase path plus dismissal, pending purchases, restore errors and ongoing subscription management. A cancelled native purchase returns to the purchase review; a successful restore uses the same activation step. A failed purchase uses the restore/retry layout with the relevant store error and a retry action. An ineligible account sees a paid subscription CTA; any trial variant must be based on verified store eligibility. Live local prices and terms replace the sample USD values in implementation.

Current source fallback prices are $39.99/year and $4.99/month; they are illustrative in these boards, not verified live offerings. The App Store screen is a concept for the system-owned sheet; native payment UI is not customizable. Android uses Google Play's corresponding native sheet. No credit-card collection screen is proposed.

## Product copy and implementation notes

- Free: three owned pets including memorialized pets; one co-carer per pet; unlimited activity logs, saved foods, medications and vaccinations.
- Pro: unlimited pets, unlimited co-carers, medical record storage and CrittrAI.
- The owner's tier sets co-care capacity. Invitees may join on Free; pending invitations reserve a slot.
- Keep an exit available, full billing cadence visible and optional setup skippable.
- The generated screens are design references, not exact production copy. In particular, recording activity does not grant permission to edit saved food, medication or vaccination settings.
- The pet-list tab bar in the first concept is illustrative; implementation keeps the app's actual Home, Schedule, Pets, Health and CrittrAI destinations.
- Suggested next iteration: simplify the review step if the store sheet already provides enough confirmation; compare benefit rows with the 2×2 benefit tiles; tune illustration size and vertical spacing on small screens.
